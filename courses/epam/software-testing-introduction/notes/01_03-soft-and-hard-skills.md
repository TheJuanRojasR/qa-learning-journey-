# 01_03 — Soft Skills and Hard Skills of a Software Tester

Every job needs two kinds of skills. **Soft skills** are about you as a person: how you think, how you talk, how you work with people. **Hard skills** are technical: you can learn them, practice them and measure them.

## Soft skills (the deck's list)

- **Enhanced responsibility** — a tester's word matters: if you say "it's tested", people trust it.
- **Good communication skills** — testers talk a lot: asking questions, explaining bugs to developers, giving status to the team.
- **Presentation skills** — you explain things to people: a demo, a report, a summary of your testing day.
- **Performance and goal oriented approach** — you work to hit goals: find defects, finish the planned tests.
- **Observation and attentiveness to details** — you notice small things; bugs hide in the details.
- **Flexible thinking and ability to learn fast** — technology changes all the time; you adapt.
- **Good abstract and analytical thinking** — you break a big feature into small pieces and think about what could go wrong.
- **Tendency to experimenting** — curiosity: "what happens if I click here twice?" Good testers try things on purpose.

## Hard skills (the deck's list)

- **Good English (B2+)** — documentation, tools, teams and courses are in English.
- **Programming basics (web and mobile)** — you don't need to be a developer, but reading code helps you test better.
- **Databases (and SQL) basics** — to check that the app really saved what it says it saved.
- **OS administration basics** — Windows / Linux: files, users, logs.
- **Network administration basics** — clients, servers, HTTP — needed for web apps and multiplayer games.
- **Virtualization and cloud computing basics** — virtual machines and test environments in the cloud.
- **Automated testing basics** — the part of the job where scripts run the tests.
- **General IT knowledge** — how software, apps and hardware work, in general.

## The ultimate minimum

> **Good English + General IT knowledge = "the ultimate minimum to start with".**

Everything else can come later, little by little.
